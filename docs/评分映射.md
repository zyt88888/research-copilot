## 2. 工程质量

| 关注点 | 做法 | 位置 |
|---|---|---|

## 4. 已知不足（建议主动说明）

1. **演示视频尚未录制**：README §11 处保留了链接占位，其余材料（分镜脚本、截图、实测数据）均已就绪。
2. **移动端未做真机适配**：页面按桌面 1920×1080 投屏设计，窄屏会退化为单列但不保证触控体验。
3. **Agent 评测集为自建**：10 条任务不等同公开 benchmark，指标用于内部回归而非横向排名。
4. **极端版式解析**：少量双栏 PDF 会出现单词粘连（如 `otherstrategies`），阅读页可对照原文核对。
5. **OCR 上限**：手写体、低分辨率扫描件识别率有限，页面会明确标记 `needs_ocr` 而不是编造文本。
